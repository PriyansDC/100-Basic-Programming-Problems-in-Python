# 🚀 100 Basic Programming Problems in Python

This repository contains my solutions to the **100 Basic Programming Problems** roadmap designed to strengthen programming logic before diving into Data Structures & Algorithms.

The problems progress from basic input/output to loops, number theory, strings, arrays, and challenge problems.

---

## 🎯 Objective

- Improve logical thinking
- Build strong programming fundamentals
- Practice writing clean code
- Prepare for DSA and LeetCode
